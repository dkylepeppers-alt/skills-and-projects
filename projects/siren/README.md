# SIREN — Marinara Engine artifacts

Engine-importable content for the SIREN setting. Story bible and prose planning live separately under the Story Skills project; this tree holds native Marinara packages.

## Layout

| Path | Role |
| --- | --- |
| `source/characters/` | Authored character cards (`.marinara.json`) |
| `build/characters/` | Disposable rebuild copies for validation and import testing |

Build outputs are ignored. Do not overwrite released snapshots in place.
